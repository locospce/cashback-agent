# Cashback Agent

AI-агент для анализа партнёрских кэшбэк-кампаний Альфа-Банка.

---

## Проблема

Менеджер партнёрского отдела получает Excel-файл с транзакциями по завершении кампании
и вручную считает метрики, ищет аномалии и принимает решение о параметрах следующей кампании.
Это занимает несколько часов и требует экспертизы в анализе данных.

**Cashback Agent** автоматизирует весь этот процесс за одно нажатие кнопки:
загрузил файл — получил готовый аналитический отчёт с рекомендациями.

---

## Что умеет

- Автоматически определяет % кэшбэка и кэп из данных (без ручного ввода)
- Сравнивает до трёх кампаний одновременно в хронологическом порядке
- Находит аномалии: переплату, подозрительных клиентов, провалы и всплески оборота
- Строит прогноз оборота тремя методами
- Рекомендует целевой сегмент и параметры следующей кампании

## Архитектура агентов

```
Загрузка файлов (1–3 Excel/CSV)
        │
        ▼
┌───────────────┐
│   Аналитик    │  Метрики по каждой таблице + сравнительный вывод Claude
└───────┬───────┘
        │
        ├──────────────────────┐
        ▼                      ▼
┌──────────────┐      ┌──────────────────┐
│   Аномалии   │      │     Прогноз      │  Линейный тренд + взвешенный + LLM
└──────────────┘      └────────┬─────────┘
                               │
                               ▼
                      ┌──────────────────┐
                      │  Сегментатор     │  ROI новых vs действующих клиентов
                      └────────┬─────────┘
                               │
                               ▼
                      ┌──────────────────┐
                      │    Стратег       │  Финальная рекомендация по кампании
                      └──────────────────┘
```

### Агенты (`agents/`)

| Файл | Роль |
|---|---|
| `analyst.py` | Считает метрики по каждому файлу; при нескольких файлах строит сравнительный анализ за один вызов LLM |
| `anomaly.py` | Статистический детектор аномалий без LLM: переплата, фрод-клиенты, провалы/всплески оборота, высокий % кэпа |
| `forecaster.py` | Три метода прогноза оборота: `numpy.polyfit`, средневзвешенный, LLM; консенсус — среднее трёх |
| `segmentor.py` | Сравнивает ROI сегментов (оборот / кэшбэк), рекомендует `new` / `existing` / `both` |
| `strategist.py` | Агрегирует все результаты, формирует финальные параметры следующей кампании |
| `copywriter.py` | Генерирует тексты офферов для Push / Баннера / SMS (отключён из UI, доступен через API) |

## Формат входных данных

Excel или CSV с колонками:

| Колонка | Описание |
|---|---|
| `SUMMA_RUE` | Сумма транзакции, руб |
| `CASHBACK_KB` | Начисленный кэшбэк, руб |
| `CLNT_ID` | ID клиента |
| `OP_DATE` | Дата транзакции |
| `CITY` | Город |

Названия колонок определяются автоматически по ключевым словам — точное совпадение не обязательно.

## Быстрый старт

### 1. Клонировать и установить зависимости

```bash
git clone <repo-url>
cd cashback-agent
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настроить API-ключ

Получить ключ на [openrouter.ai/keys](https://openrouter.ai/keys) и добавить в `.env`:

```
OPENROUTER_API_KEY=sk-or-v1-...
```

### 3. Сгенерировать демо-данные (опционально)

```bash
python generate_demo.py
```

Создаёт три файла с синтетическими транзакциями, включая намеренные аномалии для тестирования агента.

### 4. Запустить

```bash
streamlit run app.py
```

Открыть в браузере: **http://localhost:8501**

## Пример работы

```
Загружено: Январь 2024 — 200 строк | Февраль 2024 — 180 строк

Сайдбар (авто-определено из данных):
  Январь 2024:  Новые клиенты 15% · Действующие 10% · Кэп 3 000 руб
  Февраль 2024: Новые клиенты 15% · Действующие 10% · Кэп 2 500 руб

── Результаты анализа ──────────────────────────────────────────────
  Январь        Февраль
  Оборот 1.9 М  Оборот 1.7 М    ← снижение на 10%
  Кэшбек 291 К  Кэшбек 172 К
  Нагрузка 15%  Нагрузка 10%
  Клиентов 193  Клиентов 50

  Вывод: В январе кампания охватила 193 новых клиента с нагрузкой 15%.
  В феврале фокус сместился на действующих клиентов (50 чел.), что снизило
  нагрузку до 10% — более выгодный показатель для банка. Тренд положительный.

── Аномалии ────────────────────────────────────────────────────────
  [СРЕДНЯЯ] Переплата кэшбэка — 10 транзакций (5%) с кэшбэком выше 16.5%
  [ВЫСОКАЯ] Подозрительные клиенты — 1 клиент с 15 транзакциями

── Прогноз оборота ─────────────────────────────────────────────────
  Линейный тренд:   1 500 000 руб
  Средневзвешенный: 1 750 000 руб
  LLM-прогноз:      1 600 000 руб
  Консенсус:        1 616 667 руб

── Анализ сегментов ────────────────────────────────────────────────
  ROI новых клиентов:      6.67x  (100 руб кэшбэка → 667 руб оборота)
  ROI действующих:        10.00x  (100 руб кэшбэка → 1 000 руб оборота)
  Рекомендация: Оба сегмента

── Стратегия ───────────────────────────────────────────────────────
  Сегмент: Оба | Новые 15% | Действующие 10% | Кэп 3 500 руб
  Риски: Высокий % кэпнутых транзакций при росте среднего чека
```
